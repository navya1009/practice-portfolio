# Portfolio Website

## Overview
A modern, responsive, single-page portfolio website built using **HTML, CSS, JavaScript, Bootstrap 5, jQuery, and Font Awesome**. Designed to showcase your skills, projects, and contact information in a clean and professional layout.

## Features
- **Responsive Design** – Fully mobile-friendly using Bootstrap's grid system.
- **Smooth Scrolling Navigation** – Seamless section transitions with jQuery.
- **Hero Section** – Eye-catching full-screen introduction with gradient background.
- **About Section** – Profile image and bio with responsive two-column layout.
- **Projects Showcase** – Three interactive project cards with hover effects and placeholder images.
- **Contact Form** – Functional form with client-side validation and success alert.
- **Social Media Footer** – Links to GitHub, LinkedIn, and Twitter with Font Awesome icons.
- **Scroll Animations** – Sections fade in as you scroll (via jQuery).
- **Modern UI/UX** – Gradient backgrounds, shadows, rounded corners, and subtle hover animations.
